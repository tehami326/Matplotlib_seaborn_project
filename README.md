# Matplotlib & Seaborn Data Visualization Project

This repository contains my hands-on practice and projects using **Matplotlib, Seaborn, NumPy, and Pandas** to explore data visualization in Python. It includes Jupyter notebooks and Python scripts covering different plotting techniques, along with an IPL (Indian Premier League) cricket data analysis project.

## 📌 Project Overview

The goal of this repository is to strengthen my data visualization skills and learn how to transform raw datasets into meaningful visual insights using Python.

### 🎯 Objectives

- Learn and practice Matplotlib for creating customized visualizations.
- Explore Seaborn for statistical data visualization.
- Understand data loading, cleaning, grouping, and aggregation using Pandas.
- Analyze IPL cricket data to extract useful statistics and insights.
- Practice data exploration and visualization using Jupyter Notebooks.

## 🛠️ Technologies Used

- **Python** — Programming language
- **NumPy** — Numerical computing
- **Pandas** — Data manipulation and analysis
- **Matplotlib** — Data visualization and plotting
- **Seaborn** — Statistical visualization
- **Jupyter Notebook** — Interactive coding and analysis

## 📊 Topics Covered

### 1. Matplotlib
- Creating plots and figures
- Working with axes and subplots
- Customizing charts and plot layouts
- Practicing different visualization techniques

### 2. Seaborn
- Statistical data visualization
- Distribution plots
- Comparing variables visually
- Exploring relationships and patterns in data

### 3. Pandas and NumPy
- Loading CSV files using Pandas
- Exploring datasets using DataFrames
- Grouping and aggregating data

### 4. IPL Data Analysis
The IPL project uses the `IPL.csv` dataset to explore cricket match information.

The notebook imports the dataset using Pandas and practices data exploration and aggregation. The project also includes a grouped calculation of high scores by top scorer, as part of the IPL analysis.

## ⚙️ Installation and Setup

### Prerequisites
- Python 3.10 or later
- Jupyter Notebook or Visual Studio Code
- pip

### 1. Clone the repository

```bash
git clone https://github.com/tehami326/Matplotlib_seaborn_project.git
```

### 2. Navigate to the project folder

```bash
cd Matplotlib_seaborn_project
```

### 3. Install the required libraries

```bash
pip install numpy pandas matplotlib seaborn jupyter
```

### 4. Run the notebooks

Open the project in Visual Studio Code and select a Python environment with the required libraries installed. Open any `.ipynb` file and run the cells.

You can also launch Jupyter Notebook from the terminal:

```bash
jupyter notebook
```
